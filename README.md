# Material del curso-seminario

## "Gráficas en superficies, polinomios y 3-variedades"

Este repositorio reúne material académico y computacional del curso-seminario

"Gráficas en superficies, polinomios y 3-variedades"

impartido por:

- José Carlos Gómez Larrañaga
- José Luis León Medina

El curso se ofreció de enero a mayo de 2026 en CIMAT.


## Contenido del repositorio

Este material incluye, entre otros elementos:

- notas y recursos web sobre grafos en superficies;
- desarrollo de mapas combinatorios, sistemas de rotación e invariantes;
- trabajo sobre el polinomio de Bollobás-Riordan;
- experimentos computacionales para grafos de Heegaard, espacios lente y esfera de Poincaré;
- sitio en Quarto con capítulos, visualizaciones y recursos interactivos para docencia y difusión.
